How it works. The verifier computes the cryptographic hash of the file you loaded and compares it with the hash written in the certificate. If the two values match, the file is authentic and has not been modified since the artist signed it.

Green = identical to the file at the time of signing. Red = the file is different (modified, corrupted, or you are verifying the wrong file or using the wrong algorithm).

No data is ever sent to any server. The calculation takes place entirely in your browser.
