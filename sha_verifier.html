Come funziona. Il verificatore calcola l'hash crittografico del file che hai caricato e lo confronta con l'hash scritto nel certificato. Se i due valori coincidono, il file è autentico e non è stato modificato dal momento in cui l'artista lo ha firmato.

Verde = identico al momento della firma. Rosso = il file è diverso (modificato, corrotto, o è il file sbagliato).

Nessun dato viene mai inviato a server. Il calcolo avviene interamente nel tuo browser.
